# 0007 NFA exports, URL deep links, and keyboard-shortcut help

Status: accepted, Nov 2026

## Context
Tickets 08–18 delivered the core simulator: Thompson ε-NFA construction, interactive stepper, textbook mode, invariants, differential testing, stress benchmarks, and canvas zoom/pan. Several high-value usability capabilities remained in the backlog as LATER items 5, 6, and 7:
1. **NFA Exports (LATER 5)**: Ability to export the currently displayed NFA as a standalone SVG vector graphic and as Graphviz DOT text for use in academic reports, slides, and external graph toolchains.
2. **URL Deep Links (LATER 6)**: Ability to capture and restore the complete simulator configuration (regular expression, notation flavor, concatenation mode, preset, alphabet, test string, view tab, and step index) via shareable URLs.
3. **Keyboard Shortcut Help (LATER 7)**: Discoverability and accessible documentation of all keyboard navigation and canvas controls.

All additions must adhere strictly to the project invariants: Chromium-only, static single-file distribution (`dist/index.html`), zero backend, zero new runtime dependencies, zero new `window.*` globals (ADR 0004), and `src/engine/` untouched.

## Decision

### 1. NFA Exports from Cached Graphviz Data (D1, D2, D3)
- **Source of Truth**:
  - Export data originates from the cached SVG string (`renderedSvgCache`) and the Graphviz DOT string produced by `toDot()` for the currently active view and step.
  - We do not export from the live DOM because interactive user operations (hover highlight classes on nodes/edges, zoom/pan canvas CSS transforms on the viewport container) would corrupt the exported graphic.
- **Standalone SVG Formatting (`formatStandaloneSvg` in `src/ui/export.ts`)**:
  - Raw Graphviz SVGs emitted by Viz.js start with comments `<!-- Generated by graphviz version ... -->` followed by an `<svg>` root element, omitting XML declarations.
  - `formatStandaloneSvg()` is idempotent: strips any existing `<?xml ...?>`, `<!DOCTYPE ...>`, and leading generator comments, then emits a single standard `<?xml version="1.0" encoding="UTF-8"?>`.
  - Ensures required namespaces (`xmlns="http://www.w3.org/2000/svg"`, `xmlns:xlink="http://www.w3.org/1999/xlink"`).
  - Derives explicit `width` and `height` attributes from `viewBox` if missing.
  - Prepends an opaque white background rectangle (`<rect width="100%" height="100%" fill="#ffffff"/>`) directly beneath the root `<g>` so the exported graphic renders cleanly against dark document backgrounds or third-party image viewers.
- **Safe File Naming**:
  - Final view: `nfa-final.svg` and `nfa-final.dot`.
  - Step view / Textbook view: `nfa-step-<k>-<view>.svg` and `nfa-step-<k>-<view>.dot`.
  - User regular expressions are never embedded in filenames, avoiding filesystem escaping vulnerabilities, path traversal, or non-ASCII encoding pitfalls.
- **Toolbar Buttons & Size Cap Handling**:
  - `#export-svg-btn` and `#export-dot-btn` reside in `#canvas-toolbar` with stable textual labels.
  - Disabled states: initial page load, during in-flight asynchronous builds/renders, after syntax errors, and after 2,000-token engine refusals.
  - When an expression exceeds the 400 postfix token diagram cap, diagram rendering is skipped. Accordingly, SVG export is disabled, but DOT export remains fully enabled so students and researchers can process large automata in external Graphviz CLI tools.

### 2. URL Deep Links & State Serialization (D4, D5, D6, D7)
- **Query Parameter Codec (`src/ui/url.ts`)**:
  - Serializes 9 parameters: `regex`, `notation`, `concat`, `preset`, `alphabet`, `input`, `view`, `step`, `compact`.
  - No automatic `history.replaceState` during user interactions: links are generated only when the user explicitly activates the **Copy Link** button (`#copy-link-btn`).
  - Strict length budgets: whole query $\le 4,096$ characters, `regex` $\le 2,000$ characters, `input` $\le 1,000$ characters.
  - Step index is clamped to $[1, \text{totalSteps}]$; view modes exceeding size caps fallback to the allowed view.
- **Textbook Union Operator (`+`) Encoding**:
  - Standard URL decoding converts `+` to space (`%20`).
  - In textbook mode, union is represented by `+`. To survive URL parsing, `+` must be encoded as `%2B`.
  - The URL codec uses `encodeURIComponent` to guarantee safe encoding.
- **Validation & Error Handling**:
  - Invalid parameter values (e.g., malformed notation, unrecognized view, out-of-range step) are safely skipped while valid parameters continue to apply.
  - Skipped parameters are surfaced in an accessible `#link-notice` banner (`role="status"`, e.g. `"Ignored link parameters: view, step"`). Unknown query keys are ignored silently.
  - Untrusted input defense: URL parameters are applied strictly via DOM `.value` and `.textContent` properties. Escaped diagnostic messages prevent XSS.
- **Copy Link Feedback**:
  - Pure helper `copyTextToClipboard(text)` attempts `navigator.clipboard.writeText`, falling back to a hidden `<textarea>` + `document.execCommand('copy')`.
  - Transient feedback is presented solely in `#copy-link-status` (`role="status"`, `data-copied="true"|"false"`) with an automatic 2-second timer. In compliance with ADR 0004, it never writes to `#live-region`.

### 3. Accessible Keyboard Shortcut Help Modal (D8)
- **Native `<dialog>` Element**:
  - `<dialog id="keyboard-help-dialog">` rendered natively via `showModal()`.
  - Triggered by clicking `#keyboard-help-btn` or pressing the `?` key.
  - `?` trigger is guarded against typing in editable inputs (`INPUT`, `TEXTAREA`, `SELECT`, `isContentEditable`) and modifier keys (`Ctrl`, `Alt`, `Meta`).
- **Focus Trap & Suspended Background Actions**:
  - Background keyboard actions (canvas zoom/pan, ArrowLeft/ArrowRight stepping) check `dialog.open` and immediately return, preventing accidental background updates while viewing shortcuts.
  - Closing the dialog via `Esc` or `#keyboard-help-close` restores keyboard focus to the opener element.
- **Documented Shortcuts**:
  - Enter (Build), Arrow Left/Right (Step construction), `+`/`=` (Zoom in), `-`/`_` (Zoom out), `0` (Reset zoom), `f` (Fit), Shift+Arrows (Pan), `?` (Shortcut help), `Esc` (Close help).

### 4. Test Infrastructure & Mutation Verification (D9)
- Pure unit tests in Vitest verify `src/ui/export.ts` and `src/ui/url.ts` across special characters (`+`, `&`, `#`, `%`, `|`, `(`, `)`, `*`, `?`, `ε`, `∅`, non-ASCII), length limits, invalid parameter detection, and SVG prolog normalization.
- E2E tests in Playwright test real file downloads via `page.waitForEvent('download')`, inspecting XML structure and comparing exported DOT strings against the recorded render pipeline.
- Deep link test cases run in freshly instantiated browser pages to guarantee isolation without polluting the shared test harness page.
- Every acceptance criterion is paired with dedicated automated UI mutants evaluated via `tests/ui-mutants.cjs`.

## Consequences
- The production distribution remains a single, offline HTML bundle (`dist/index.html`) under 1.47 MB.
- Zero new runtime dependencies or external libraries introduced.
- Invariants I1–I4, ADR 0004 compliance, and `src/engine/` integrity are fully maintained.
- Users can reliably share reproducible automata states and export publication-ready vector assets directly from the browser.
